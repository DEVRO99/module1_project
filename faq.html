Order FAQs:



ပစ္စည်းမှာပြီးရင် ဘယ်နှရက်အတွင်း ပို့ပေးလဲ?


မန္တလေးမြို့တွင်းနဲ့ ရန်ကုန်မြို့တွင်း Order များကို Order တင်ပြီး (၂) ရက်မှ (၃) ရက်အတွင်း ပို့ဆောင်ပေးမည် ဖြစ်ပါသည်။ တခြားမြို့/နယ်မှ Order များကိုတော့ Order တင်ပြီး နောက်တစ်ရက်တွင် ကားဂိတ်အထိပို့ဆောင်ခ (၂,၀၀၀) ကျပ်ဖြင့် Customer ဘက်မှတောင်းဆိုသော ကားဂိတ်/ Delivery Service များမှတစ်ဆင့် ပို့ဆောင်ပေးပါသည်။ သက်ဆိုင်ရာကားဂိတ်အတွက် တန်ဆာခကို Customer ဘက်မှ ကျသင့်မည် ဖြစ်ပါသည်။



လာပို့တဲ့ ပစ္စည်းမှာ Factory Error ပါလာရင် ဘယ်လိုလုပ်ရမလဲ?


ပစ္စည်းလက်ခံရရှိပြီးနောက် မှာယူထားသောပစ္စည်း၌ Factory Error ပါကြောင်းတွေ့ရှိပါက ဝယ်စဉ်ကအတိုင်း အပွန်းအစင်းအနာအဆာမရှိဘဲ ဗူးပါကင် ပစ္စည်းအစုံအလင်ဖြင့် ဆိုင်သို့ ဝယ်ယူပြီး (၃) ရက်အတွင်း ဆက်သွယ်ပြီး ပြန်လည်ပို့ဆောင်ပေးရမည်ဖြစ်ပါသည်။ ဆိုင်သို့ ပစ္စည်းပြန်ရောက်သည်နှင့် ပစ္စည်းကို အသေးစိတ်သေချာ ပြန်လည်စစ်ဆေးပေးသွားမည်ဖြစ်ပြီး Factory Error ဖြစ်ကြောင်းမှန်ကန်ပါက အဆင်ပြေအောင် ပြန်လည်ဆောင်ရွက်ပေးမည် ဖြစ်ပါသည်။
